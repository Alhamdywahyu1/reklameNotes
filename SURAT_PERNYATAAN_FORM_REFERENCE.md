## Data Form Breakdown

### Section 1: Data Pemohon
| Field | Type | Required | Example |
|-------|------|----------|---------|
| Nama Pemohon | Text | ✅ | PT. Sinar Reklame Bangkalan |
| Pekerjaan | Text | ✅ | Pengusaha / Direktur |
| Alamat Pemohon | Textarea | ✅ | Jl. Sudirman No. 45, RT/RW 02/03, Bangkalan, Jawa Timur |
| No KTP | Text | ✅ | 3515011234567890 |

### Section 2: Syarat & Ketentuan (Checkboxes)
- Syarat 1: Mematuhi peraturan Kabupaten Bangkalan
- Syarat 2: Untuk kepentingan reklame sesuai ketentuan
- Syarat 3: Tidak mengubah konstruksi/lokasi tanpa izin
- Syarat 4: Tidak memindah tangankan izin tanpa persetujuan
- Syarat 5: Bertanggung jawab konstruksi, kebersihan, keindahan
- Syarat 6: Bertanggung jawab atas kecelakaan/kerugian pihak lain
- Syarat 7: Bongkar reklame maksimal 7 hari setelah masa berlaku habis
- Syarat 8: Menerima pembongkaran/sanksi jika melanggar

### Section 3: Dokumen Pendukung
| Field | Type | Required | Format | Max Size | Notes |
|-------|------|----------|--------|----------|-------|
| Tanggal Pernyataan | Date | ✅ | YYYY-MM-DD | - | Tanggal pembuatan surat |
| File Tanda Tangan | File | ⭕ | PDF/JPG/PNG | 5MB | Bukti tandatangan |
| File Materai | File | ⭕ | PDF/JPG/PNG | 5MB | Bukti materai Rp 10.000 |

## Key UI Elements

### Buttons
- **Buat Surat Pernyataan** - Primary (Blue)
- **Edit** - Warning (Yellow)
- **Lihat** - Info (Cyan)
- **Download PDF** - Outline Primary
- **Simpan & Submit** - Primary (Blue)
- **Kembali** - Secondary (Gray)

### Badges
- **Status Draft** - Warning (Yellow)
- **Status Submitted** - Info (Cyan)
- **Status Verified** - Success (Green)
- **Status Rejected** - Danger (Red)

### Alerts
- **Info** - Blue background (untuk informasi penting)
- **Danger** - Red background (untuk keterangan penolakan)
- **Success** - Green background (untuk konfirmasi sukses)
